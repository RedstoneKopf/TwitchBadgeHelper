## 2025-03-01 - Optimizing GDI+ DrawImage Performance
**Learning:** In GDI+ (`System.Drawing`), drawing images onto a newly created transparent `Bitmap` using default settings is unnecessarily slow due to alpha-blending math. The default `CompositingMode` is `SourceOver`. Setting it to `SourceCopy` bypasses blending and directly copies pixels, improving performance. Additionally, calling `Graphics.Clear(Color.Transparent)` on a new `Bitmap` is redundant because new bitmaps are already initialized to transparent (ARGB 0,0,0,0). `SmoothingMode` has no effect on `DrawImage`, only on vector graphics.
**Action:** When resizing or copying images using `System.Drawing`, set `CompositingMode` to `SourceCopy` when drawing onto a blank or transparent canvas to bypass alpha blending overhead. Avoid redundant `Clear` calls on new bitmaps.
